# Your Attention Is for Sale

A bilingual (EN/ES) interactive EL reading lesson for grades 9–12 — read-aloud passage with sentence highlighting, clickable vocabulary, bell ringer, hook, "feel the tricks" fake feed, stop-and-jot, app-design task, vocabulary match with streaks, five ELPA21-style auto-graded test prep items, O·R·E·A·C exit ticket, and an attention-check lock.

Live: https://radan55.github.io/Stormattention/  
Agenda board (projector): https://radan55.github.io/Stormattention/agenda.html

**Teacher notes**
- Unlock code for the attention-check pop-up: see `TEACHER_CODE` in `index.html` (currently `1103`).
- Exit tickets (name, class period, O·R·E·A·C paragraph) submit to the Jotform at `FORM_URL` in `index.html`; test prep is graded on the page only.
- Audio uses the browser's built-in voices (best in Chrome/Edge).
